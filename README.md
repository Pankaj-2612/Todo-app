# 📝 Todo App

## 🚀 Overview

Todo App is a modern and fully responsive task management application built using **React + Vite**.  
The application helps users organize daily tasks efficiently with a clean UI and smooth user experience.

This project focuses on simplicity, performance, and responsiveness while implementing important frontend concepts like:

- React Components
- State Management
- Local Storage
- Conditional Rendering
- Responsive Design

All todos are stored in the browser's **Local Storage**, ensuring that your tasks remain saved even after:

- Refreshing the page
- Closing the browser
- Reopening the application later

The app also supports editing tasks, deleting tasks, and viewing completed todos separately.

---

# ✨ Features

## ✅ Add Todos
Create and save tasks quickly using the input field.

## ✏️ Edit Todos
Modify existing tasks anytime using the edit icon.

## 🗑️ Delete Todos
Remove tasks instantly using the delete icon.

## 💾 Local Storage Support
Todos are permanently stored in the browser's Local Storage.

## ✔️ Finished Todos
Option available to view completed tasks separately.

## 📱 Fully Responsive Design
Optimized for:

- Mobile Devices
- Tablets
- Laptops
- Desktop Screens

## 🎨 Icon-Based Actions
Uses **Hugeicons** for edit and delete actions instead of traditional buttons for a cleaner UI.

## ⚡ Fast Performance
Built with **Vite**, providing extremely fast development and build performance.

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Pankaj-2612/todo-app.git
```

## 2️⃣ Navigate to Project Directory

```bash
cd todo-app
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```

The app will run on:

```bash
http://localhost:5173
```

# 💡 How Local Storage Works

The application uses the browser's **Local Storage API** to save all todos directly in the user's browser.

### Benefits

- No backend required
- Fast and lightweight
- Persistent data storage
- Tasks remain saved after refresh or browser restart
